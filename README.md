# Personal Portfolio Website

A simple and responsive personal portfolio website built using HTML and CSS. This project showcases my profile, skills, projects, and contact section.

## 📌 About the Project

This portfolio website was developed as part of my frontend learning journey at DecodeLabs. It demonstrates the use of HTML5 and CSS3 to create a clean and responsive webpage.

## ✨ Features

- Responsive navigation bar
- Hero section with introduction
- About Me section
- Projects showcase
- Contact form
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
