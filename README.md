# Decode-Labs

Frontend Development Industrial Training Kit — Batch 2026.

This repository contains my project submissions for the DecodeLabs Frontend Development training program. Each project builds on the last, moving from static layout basics to responsive design to interactive JavaScript.

## Projects

| # | Project | Focus | Link |
|---|---------|-------|------|
| 1 | Personal Portfolio Page | HTML structure, Flexbox nav, CSS Grid project cards | [Project-1](./Project-1) |
| 2 | Responsive Web Layout | Mobile-first CSS, media queries, responsive nav | [Project-2](./Project-2) |

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Vanilla JavaScript (no frameworks or libraries)

Each project folder is self-contained and can be run independently — just open its `index.html` in a browser. See each project's own `README.md` for details on what it covers and how it's structured.

```

```
