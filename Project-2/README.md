# Project 2 — Responsive Web Layout

Part of the DecodeLabs Frontend Development Industrial Training Kit (Batch 2026).

## Overview

A fully responsive one-page website for **Fernweg Trail Co.**, a fictional small-batch hiking gear shop, built to demonstrate responsive design fundamentals — fluid layouts, flexible navigation, and clean breakpoints from mobile to desktop.

## Live Preview

Open `index.html` in any browser. No build step or server required.

## Features

- **Mobile-first CSS** — base styles target small screens first, then scale up
- **Responsive navigation** — collapses into a hamburger menu on smaller screens, expands to a full nav bar on desktop
- **CSS Grid** — used for the product catalog layout
- **Flexbox** — used for the navbar and content sections
- **Media queries** at two breakpoints:
  - `768px` — tablets and below (hamburger nav appears, 2-column product grid)
  - `480px` — mobile phones (single-column layout, smaller type)

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Vanilla JavaScript (hamburger menu toggle)
