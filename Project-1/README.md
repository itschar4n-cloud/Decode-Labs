# Project 1 — Personal Portfolio Page

Part of the DecodeLabs Frontend Development Industrial Training Kit (Batch 2026).

## Overview

A personal portfolio website for **Mamidi Charan**, built as an introduction to core HTML structure and CSS layout. The page presents a short bio, a grid of featured projects, and a working contact form layout.

## Live Preview

Open `index.html` in any browser. No build step or server required.

## Features

- **Header & navigation** — sticky-style header with a logo and a Flexbox nav bar linking to each section
- **Hero section** — introductory heading, tagline, and a call-to-action button
- **About section** — short bio text in a centered, readable column
- **Projects grid** — three project cards (Crime Rate Prediction, Portfolio, Web Scraping) laid out with **CSS Grid**, each with an image, title, and description
- **Contact form** — name, email, and message fields with a styled submit button (front-end layout only, not wired to a backend)
- **Footer** — simple copyright line

## Tech Stack

- HTML5
- CSS3 (Flexbox for navigation, Grid for the project cards)

## How to Run

1. Clone or download this folder, keeping the `css/` and `assets/images/` subfolders intact.
2. Open `index.html` directly in a browser.

## What I Practiced

- Semantic HTML structure (`header`, `main`, `section`, `footer`)
- Flexbox for navigation layout
- CSS Grid for a multi-card project layout
- Styling a basic HTML form
- Organizing a project into folders (`css/`, `assets/images/`) instead of one flat directory
